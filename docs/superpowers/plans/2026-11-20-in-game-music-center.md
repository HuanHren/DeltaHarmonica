**架构**　沿用现有悬浮服务、目录仓储、事务保存和演奏器。Root 授权与更新检查分别采用进程级状态，曲谱预检复用既有解码与转换。

- [x] 用状态迁移测试验证 Root 冷启动、拒绝、撤销和回退，再连接现有 Root 与无障碍后端。
- [x] 用实际格式与失败样例验证统一兼容性报告与缓存键，保留既有调度时序。
- [x] 用正式版元数据和失败用例验证更新检查、下载与 APK 校验，经系统安装流程提示确认。
