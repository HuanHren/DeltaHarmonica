# 设置与游戏内校准

## 设置入口

| 设置 | 可执行的操作 |
| --- | --- |
| 演奏与输入 | 选择输入后端、默认范围和速度，管理音量键快捷操作 |
| 悬浮窗与游戏内控制 | 管理悬浮窗权限，打开游戏内播放器 |
| 校准与布局 | 编辑布局、打开游戏内校准、测试已保存布局 |
| 曲库与导入 | 浏览已保存曲目，导入 MIDI 或 JSON |
| 权限与系统 | 打开系统无障碍设置，调整主题、语言、界面大小及桌面图标 |
| 关于与诊断 | 查看版本、项目和许可，展开输入诊断以检查或刷新后端状态 |

## 在游戏中校准

1. 允许悬浮窗权限，然后从「校准与布局」打开「游戏内校准」。
2. 切到游戏的横屏口琴界面，点击悬浮胶囊展开。拖动胶囊或展开面板的标题可以移动面板，应用会按屏幕方向记住位置。
3. 进入「位置」，拖动标记或选中校准目标，用 X／Y 轴的 ±250 像素按钮微调。对齐 8 个音键、3 个音区控制点和半音控制点后保存，再确认坐标。
4. 使用「测试点击」检查当前目标，或在「按键测试」验证短按和长按并调整长按时长。
5. 在「音区与半音」按游戏显示同步当前音区及半音开关。同步用于登记已观察到的游戏状态。「向游戏发送」会向已校准的位置派发操作。

「隐藏标记」可临时腾出游戏画面。收起按钮会让校准面板回到胶囊状态。保存布局后，从游戏内播放器选择曲目、范围和速度，再开始演奏。
