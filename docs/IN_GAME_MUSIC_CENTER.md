# 游戏内音乐中心

## 使用

从「设置 → 悬浮窗与游戏内控制」打开悬浮胶囊，展开迷你播放器，再点「音乐中心」。曲库按最近更新展示，可按曲名、作者、上传者或标签搜索，逐批加载，查看曲谱详情、下载、收藏或进入演奏确认。本地栏读取已保存曲目，最近播放沿用现有记录，收藏及搜索历史保存在本机。

「下载并演奏」会复用本地已有文件，或从公开 CDN 拉取 DFHS1、预检、转换并事务保存后载入曲目。演奏依旧经过游戏音区、半音和控制点确认。下载错误会显示在当前详情，已载入的曲目与播放状态仍可用。

迷你播放器可选 1×、2×、播放范围、上下曲和媒体音量。开始演奏后，原悬浮面板由紧凑的暂停、继续与停止控件接管。校准触点和停止栏周围有足够空间时，可在演奏中展开曲库或仅下载。Root 演奏时浮窗保持非焦点模式。无障碍演奏先暂停再浏览，以免手势相互取消。停止后可使用键盘输入。演奏中从曲库控件选上、下一首时，先完成当前会话的停止和触点释放，再载入目标曲目并进入确认。

## 窗口与数据

CalibrationOverlayService 持有 WindowManager、播放会话与面板生命周期。GamePlayerPanel 在胶囊、迷你播放器、曲库、同步和开始确认间切换。GameMusicCenter 复用应用范围的 AppViewModel、OnlineLibraryRepository 与 SongLibraryRepository。搜索过滤、CDN 读取、解码、转换和播放规划在后台执行。演奏控制栏和曲库位置按当前屏幕与校准触点计算。窗口移除与会话恢复也会清理临时音乐中心和键盘焦点。

目录、详情和 DFHS1 来自 [公开 CloudBase 曲库](ONLINE_LIBRARY.md)，从该目录展示更新时间和已有元数据。收藏为本地选择。旧 CDN 暂无可接入的日榜、周榜、累计下载量或点赞数据，本轮实现范围省略排行榜、下载统计和点赞。

## Root 授权

「设置 → 权限与系统」展示 Root 环境、管理器、最近授权验证结果和配置的演奏后端。进程启动时通过可见的 su 路径和管理器信息检查环境，并读取 DataStore 中的授权记录。已保存的 Root 偏好在首次实际使用时执行一次有时间上限的验证。手动重新申请通过当前 Root 管理器发起。

可见的 Magisk、KernelSU 和 APatch 由包名识别。系统限制了隐藏管理器和定制分支的识别。三种管理器之间缺少既有统一的非交互授权 API，应用以内存中的本进程验证结果和持久化历史区分已验证与待验证。拒绝、撤销、管理器变化和 helper 初始化失败后更新状态，已有的无障碍通路可回退。触摸释放状态不确定时，现有播放保护继续阻止派发。

## 兼容性与调度

MIDI、RMID、ZIP 内单个 MIDI、JSON 演奏脚本和 DFHS1 共用兼容性状态。报告区分完全兼容、适配后兼容、部分兼容和不兼容。报告和既有预检展示合并或未映射音符及阻止播放的原因。MusicXML 留待格式支持。

转换缓存按原始曲谱 SHA-256、解析与转换版本、乐器 Profile、布局、音轨、移调和单音化选项分键。缓存为有界进程内缓存，保留原有事务保存和本地 SHA-256 校验。读取、解码、转换和规划时长在开发诊断中通过 DeltaScore 记录。调度沿用已有输入阶段、触点清理与时间测量。

## 正式版更新

「设置 → 版本更新」默认自动检查，可关闭，也可手动检查。正式包每个新进程最多自动向 HuanHren/DeltaHarmonica 的 GitHub Releases latest 检查一次，启动界面无需等待请求。正式版发布可在更新说明单独声明 versionCode。较早的正式版资产用数字版本筛选提示，确认覆盖前总是以 APK 内实际 versionCode 比较。

GitHub Release 必须包含约定的正式 APK 文件名和资产 SHA-256。APK 下载比对官方 URL、重定向域名、字节数与 SHA-256，再校验候选包名、版本和与已安装应用一致的签名证书。用户选择安装后进入 Android 系统确认流程，沿用原签名证书和应用数据。
